    スクリーニングとウォッチリストの違い

    スクリーニング — このサイトが毎日自動で「今日この条件を満たす銘柄」を選んで表示する機能です。バリュー株・グロース株・ディフェンシブ株・シナリオ別の4つのタブから選べます。

    ウォッチリスト — あなた自身が「常時モニタリングしたい」と思う銘柄を自由に登録できる機能です。ページを開くたびに最新の終値・RSI・MACDトレンドが表示されます。スクリーニングに出てこない銘柄でも登録できます。スクリーニング表の ★ を押すか、ウォッチリストの「＋ 銘柄を追加」から検索して登録してください。

    4つのスクリーニングタブについて

    💎 割安×上昇開始（バリュー株） — 利益や資産に対して株価が安く（PER・PBRが低い）、配当ももらえて、かつ株価が上昇に転じ始めた銘柄です。じっくり保有するスタイルに向いています。

    🚀 高成長×勢い（グロース株） — 売上・利益が大きく伸びていて、株価も強い上昇の勢いを保っている銘柄です。値動きが大きいためリスクも高めです。条件が厳しいため該当ゼロの日が多いのは正常です。なお、コカ・コーラのような成熟した安定企業が好決算の四半期に紛れ込まないよう、生活必需品・公益セクターと高配当（2%超）の銘柄はグロースから除外しています。

    🛡️ 守り×安定配当（ディフェンシブ株） — 景気に左右されにくい業種（生活必需品・公益・ヘルスケア）の中から、値動きが市場平均より穏やかで（ベータ1以下）、配当が厚く、長期上昇トレンドにある銘柄です。相場が不安定な時期の「守りの選択肢」です。

    🌍 シナリオ別 — 「中東情勢はどうなる？」「FRBはタカ派？ハト派？」「日銀は利上げを続けるか？」「次の選挙で何が変わるか？」「核融合・半導体AI分野で日本は伸びるか？」など、あなた自身の相場予想を選ぶと、その予想に対応した注目テーマ・銘柄を表示します。スクリーニングではなく教科書的な対応関係の提示です。

    各指標の意味

    スコア
    選択中の戦略の条件を、どれだけ余裕を持って満たしたかの目安（0〜100）。上昇確率の予測ではありません。 同日の候補の中での「調べる優先順位」に使ってください。戦略タブを切り替えると、その戦略向けに計算し直した値に変わります（同じ銘柄でも割安重視のときと成長重視のときで点数が変わります）。「—」はその戦略の判定に必要な指標が無い銘柄です（例: 金融株は成長率が取れずグロースのスコアが付きません）。加点内訳はタブ下の選定基準バナーに表示しています。
    PER（株価収益率）
    株価が1株あたり利益の何倍か。低いほど利益に対して割安。日本株14倍以下・米国株18倍以下で抽出しています。
    PBR（株価純資産倍率）
    株価が1株あたり純資産の何倍か。1倍以下は会社の解散価値より安い状態。
    配当利回り
    株価に対して年間いくら配当がもらえるか。3%なら100万円分の株で年3万円（税引前）。
    ROE（自己資本利益率）
    会社の「稼ぐ力」。8%以上を条件にして、安いだけで稼げない会社（バリュートラップ）を除外しています。ただしROEは借金（レバレッジ）で水増しできるため、D/E比率と合わせて見ることを推奨します。
    D/E（負債資本倍率）
    負債÷自己資本の比率（バリュー株タブで表示）。1倍超は負債が自己資本より多い状態。1倍超は琥珀色、2倍超は赤で表示。銀行・保険・公益業種は業種の構造上、高くなりやすいため業種を考慮して見てください。
    配当性向
    配当÷純利益の比率（ディフェンシブ株タブで表示）。85%超は減配リスクゾーン（スコア減点）、100%超は利益以上の配当（タコ足配当）で赤表示します。高配当を選ぶ際の重要チェック項目です。
    RSI
    買われすぎ・売られすぎの体温計（0〜100）。70以上は過熱気味、30以下は売られすぎが目安。
    売上成長 / EPS成長
    直近四半期の前年同期比。EPSは1株あたり利益。※通期の成長率ではない点に注意。また、不動産売却などによる特別利益でEPSが一時的に急増した銘柄が混ざる可能性があります（売上成長との同時確認で低減しています）。最終判断は各社の決算資料でご確認ください。
    CCI / %K・%D
    株価の勢い（モメンタム）を測る指標。CCI100以上・ストキャスティクス80以上は「強い上昇が続いている」状態。
    乖離
    25日移動平均線から何%上に離れているか。大きすぎる（急騰しすぎ）銘柄は除外済み。
    ベータ
    市場全体に対する値動きの大きさ。1なら市場並み、1未満なら市場より穏やか。ディフェンシブ株は1以下を条件にしています。
    200日線
    過去200営業日の平均株価。終値がこの上にあれば長期の上昇トレンドと判断します。

    使い方のコツ

    • 表にはどの戦略でも全指標を共通で表示します。割安タブでも成長率やベータを見られるので、銘柄を多角的に比較できます。
    • スコアは選択中の戦略に連動します。戦略タブを切り替えると、ウォッチリストのスコアも同じ基準で再計算されます。
    • 「標準」で該当ゼロの日は「ゆるめ」に切り替えると、惜しい銘柄をウォッチできます。
    • スクリーニング表の ★ を押すか、ウォッチリストの「＋ 銘柄を追加」から登録した銘柄は、ウォッチリストに常時表示されます。
    • 銘柄名のリンクから Yahoo!ファイナンス等で詳細を確認してから判断しましょう。

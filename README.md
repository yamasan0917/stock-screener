# 日米株 日次スクリーニングツール／本日のおすすめ銘柄

日本株と米国株を対象に、3つの戦略（バリュー・グロース・ディフェンシブ）で銘柄を
自動抽出するツールです。ウェブ版には相場予想に合わせて注目銘柄を出し分ける
「シナリオ別おすすめ」もあります。APIキー不要・無料で動きます。

**2つの使い方があります:**

| 形態 | 入口 | 説明 |
|---|---|---|
| 🌐 ウェブ版「本日のおすすめ銘柄」 | `docs/` + `generate_data.py` | 1日2回自動更新の静的サイト。公開手順は **[WEB_GUIDE.md](WEB_GUIDE.md)** |
| 💻 CLI版 | `screener.py` | ターミナルで実行して表とCSVを出力 |

ウェブ版は拡張ユニバース（米: S&P500+S&P400+NASDAQ100+ウォッチリスト ≒1,040銘柄 /
日: TOPIX500+東証グロース市場+日経225 ≒1,100銘柄）、日本語社名・カタカナ表示に対応しています。

> Gemini Deep Research版仕様書の問題点を修正した上で実装しています。
> 修正内容の詳細は [SPEC_REVIEW.md](SPEC_REVIEW.md) を参照してください。

## セットアップ

```powershell
pip install -r requirements.txt
```

必要なもの: Python 3.10以上、インターネット接続。APIキーは不要です。

## 使い方

```powershell
# 基本（日米両方・両戦略・約3分）
python screener.py

# 日本株のみ / 米国株のみ
python screener.py --market jp
python screener.py --market us

# 戦略を絞る（バリュー / グロース / ディフェンシブ）
python screener.py --strategy value
python screener.py --strategy growth
python screener.py --strategy defensive

# 緩和プリセット（標準で該当ゼロの日に「惜しい銘柄」を観察する用）
python screener.py --loose

# 自分のウォッチリストでスクリーニング（1行1銘柄。日本株は4桁コードだけでOK）
python screener.py --universe-file my_list.txt --market jp

# 動作確認（先頭20銘柄だけで高速実行）
python screener.py --limit 20
```

結果はコンソール表示に加えて `results/` フォルダに CSV（Excelでそのまま開けます）
で保存されます。同じ日の再実行は価格データのキャッシュを使うため高速です。

## 3つの戦略（初心者向け解説）

### タブ1: バリュー株 × 上昇トレンド

「**割安に放置されていた銘柄が、上昇に転じ始めた瞬間**」を狙う戦略です。

| 条件 | 日本株 | 米国株 | 意味 |
|---|---|---|---|
| PER | 14倍以下 | 18倍以下 | 利益に対して株価が割安 |
| PBR | 1.2倍以下 | 2.5倍以下 | 資産に対して株価が割安 |
| 配当利回り | 3%以上 | 2%以上 | 待っている間も配当が入る |
| ROE | 8%以上 | 10%以上 | 割安でも「稼ぐ力」はある（万年割安株の排除） |
| 配当性向 | 100%以下 | 100%以下 | 利益以上の配当（タコ足配当）＝減配リスクを除外 |
| D/E比率 | 2倍以下 | 2倍以下 | 過剰債務のバリュートラップを除外（金融セクターは対象外） |
| 終値 > 200日線 | 共通 | | 長期下降トレンド（落ちるナイフ）を除外 |
| 終値 > 50日線 | 共通 | | 中期トレンドが上向き圏 |
| 25日線 > 50日線（または直近5日でゴールデンクロス） | 共通 | | 上昇への転換 |
| MACD > シグナル | 共通 | | 短期の勢いも上向き |
| RSI 40〜65 | 共通 | | 急騰しすぎていない（=まだ乗れる位置） |
| 売買代金 | 3億円/日以上 | $10M/日以上 | 売買が薄い銘柄を除外 |

### タブ2: 高成長グロース株 × モメンタム

「**業績が高成長で、株価も強い上昇の真っ最中**」の銘柄を狙う戦略です。
順張り（強いものに乗る）の考え方で、条件が全部揃う銘柄は少ないのが正常です。

| 条件 | 値 | 意味 |
|---|---|---|
| 売上成長率 | +15%以上 | 直近四半期の前年同期比 |
| EPS成長率 | +20%以上 | 利益も伸びている |
| RSI 65〜85 | | 強い買いの勢い（ただし極端な過熱は除外） |
| CCI ≥ 100 | | ブレイクアウト状態 |
| ストキャス %K・%D ≥ 80 | | 高値圏に張り付く強さ（エンベデッド） |
| 終値 > 25日線、かつ乖離20%以内 | | 上昇中だが急騰しすぎていない |
| セクター除外 | 生活必需品・公益は対象外 | 成熟ディフェンシブ企業の誤分類防止（コカ・コーラ問題） |
| 配当利回り 2%以下 | | 高配当企業は利益を成長投資に回していない＝グロースではない |

> 該当ゼロの日が多い戦略です。`--loose` で条件を緩めた候補も確認できます。
> （`--loose` でもセクター除外・配当上限の「スタイル定義」は緩めません）

### タブ3: ディフェンシブ株 × 安定配当

「**景気や相場の変動に強い銘柄で守りを固める**」戦略です。

| 条件 | 日本株 | 米国株 | 意味 |
|---|---|---|---|
| セクター | 生活必需品・公益・ヘルスケアのみ | 同左 | 景気に左右されにくい業種 |
| 配当利回り | 2.5%以上 | 2%以上 | 保有している間の安定収入 |
| PER | 18倍以下 | 22倍以下 | 割高なディフェンシブは除外 |
| ROE | 8%以上 | 10%以上 | 稼ぐ力のある会社に限定 |
| ベータ | 1.0以下 | 1.0以下 | 市場平均より値動きが穏やか |
| 配当性向 | 100%以下 | 100%以下 | タコ足配当（減配リスク大）を除外 |
| D/E比率 | 3倍以下 | 3倍以下 | 過剰債務を除外（公益は設備産業のためバリューより緩め） |
| 終値 > 200日線 | 共通 | | 長期上昇トレンドにある |
| RSI 35〜70 | 共通 | | 異常な売られ方・過熱をしていない |

### シナリオ別おすすめ（ウェブ版のみ）

「中東情勢は緊迫が続く？沈静化する？」「FRBはタカ派？ハト派？」「円安継続？円高転換？」
「米中間選挙はどちらが優勢？」——ユーザー自身の相場予想を選ぶと、その予想に対応した
注目テーマ・銘柄（理由付き）を日米それぞれ表示します。

これはスクリーニング結果ではなく「予想とテーマの教科書的な対応表」（編集コンテンツ）です。
銘柄リストは `scenarios.py` に集約されており、時事に合わせて自由に編集できます
（編集したら `EDITORIAL_DATE` も更新してください）。

### スコアの見方

各銘柄に 0〜100 点のスコアを付けて降順に表示します。これは
「**条件をどれだけ余裕を持って満たしたか**」の目安であり、上昇確率の予測では
ありません。同日の候補の中でどれから調べるかの優先順位付けに使ってください。

### ROIC（投下資本利益率）— 全戦略共通のクオリティ指標

ROIC は「**会社が事業に投じたお金（借入＋株主資本）からどれだけ効率よく
税引後利益を生んだか**」を示す指標で、ROE と違い借金でかさ上げできないため
「本当に強いビジネスか」を見るのに適しています。

表示は `28.5% (4年) ↗` の形式です:

| 要素 | 意味 |
|---|---|
| 数値 | **過去最大4年の平均ROIC**（単年だと一時要因で歪むため平均で見る） |
| (N年) | 平均の対象年数。**3年未満は参考程度**（IPO直後は投下資本が小さく見かけのROICが異常に高く出るため） |
| ↗ / → / ↘ | 4年間の傾向。↗は競争優位が強まっているシグナル（例: Apple）、↘は要注意 |

目安: **8%（資本コスト相当）が損益分岐点**で、それ未満が続く企業は事業を
続けるほど価値を毀損している可能性があります。15〜20%以上を長年維持する企業
（Apple ≒60%、Microsoft ≒30%）は強い「堀」を持つ優良企業です。

スコアへの反映: 平均ROIC 8%超で加点が始まり20%で満点（最大8点）、増加傾向で
さらに+2点のボーナスとして加算します。**足切り条件にはしていません**——
銀行・保険はROICの概念が合わず計算不能（「—」表示）になるためで、
ROICが見えない＝悪い会社ではありません。閾値は `config.py` で変更できます。

## カスタマイズ

すべての閾値は `config.py` に集約されています。例:

- PER/PBR/配当/ROEの基準を変える → `standard_config()` の数値を編集
- ROEフィルターを外す → `roe_min=0.0`
- 売買代金の下限を変える → `min_value_traded`
- RSIの帯を変える → `rsi_min` / `rsi_max`

## 毎日自動実行したい場合（Windows）

タスクスケジューラに以下を登録すると、毎営業日の取引終了後に自動実行できます。

推奨時刻: 日本株 16:00以降 / 米国株 朝7:00以降（日本時間）
```

.github/workflows/ # 1日2回の自動更新（GitHub Actions）

```

## 既知の制約

- データは yfinance（非公式Yahoo Finance API）。個人利用の範囲で使ってください
- 日本株のPERは「実績ベース」です（証券アプリの会社予想PERと差が出ます）
- 成長率は「直近四半期の前年同期比」で、通期成長率ではありません
- より正確な日本株ファンダが必要な場合は J-Quants API の導入を推奨
  （SPEC_REVIEW.md 第4章参照）
